# 🌿 Green Supply Chain Guardian

**AI-Powered Sustainability Platform for Modern Supply Chains**

Monitor carbon emissions, score supplier ESG performance, and optimize logistics routes — all powered by machine learning for a greener tomorrow.

## Quick Start

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## About

Green Supply Chain Guardian (GSCG) is an enterprise-grade platform designed to help organizations measure, manage, and minimize the environmental impact of their entire supply chain.

> 📖 For full documentation, architecture diagrams, and roadmap, see [PROJECT_README.md](PROJECT_README.md)

## Features

- 📊 **Dashboard** — Real-time KPIs, charts, and activity feed
- 👥 **Supplier Management** — ESG scoring, risk classification, certifications
- 📉 **Carbon Tracking** — Scope 1/2/3 emissions, hotspots, carbon calculator
- 🚛 **Logistics** — Shipment tracking, transport mode analysis, route optimization
- 📋 **Reports & Compliance** — GHG Protocol, CSRD, ISO 14064, SBTi, CDP, TCFD
- ⚙️ **Settings** — Profile, notifications, integrations, API keys

## Tech Stack

- **Vite 6** — Build tool
- **Vanilla JS** — Zero-dependency frontend
- **Chart.js 4** — Data visualizations
- **CSS Custom Properties** — Premium design system
- **AI-Generated Images** — Hero and section backgrounds
